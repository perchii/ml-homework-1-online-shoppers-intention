# Домашнее задание №1: Online Shoppers Intention

Проект по бинарной классификации: предсказание того, завершится ли пользовательская сессия в интернет-магазине покупкой (`Revenue`).

## Датасет

Используется датасет [Online Shoppers Purchasing Intention Dataset](https://www.kaggle.com/datasets/imakash3011/online-shoppers-purchasing-intention-dataset). Он содержит 12 330 пользовательских сессий и признаки поведения на сайте, технические характеристики и контекст визита.

## Гипотезы

1. Технические характеристики браузера, ОС и части источников трафика менее важны, чем поведенческие признаки сессии.
2. Пользователи совершают покупки существенно реже, чем покидают сайт без покупки; поэтому одной Accuracy недостаточно для оценки моделей.
3. Вероятность покупки зависит от месяца: в данных наблюдается сезонность конверсии.
4. L1-регуляризация позволит сократить число признаков без существенного ухудшения качества.
5. При увеличении глубины дерева качество на обучающей выборке будет расти, а на тестовой после некоторого значения начнёт снижаться.
6. Random Forest превзойдёт одиночное дерево решений по ROC AUC и F1 macro.

## Результаты

- Данные несбалансированы: положительный класс `Revenue=True` встречается заметно реже.
- `PageValues` оказался наиболее важным признаком по встроенной важности Random Forest и permutation importance.
- Глубокое дерево решений переобучается; наилучший баланс для одиночного дерева наблюдался около `max_depth=5`.
- Random Forest стал лучшей моделью по кросс-валидации: ROC AUC = 0.926, F1 macro = 0.784.
- После GridSearchCV лучшая конфигурация Random Forest достигла ROC AUC = 0.919 на внешнем тестовом наборе.
- Отбор 20 наиболее важных признаков не ухудшил качество на текущем тестовом разбиении: ROC AUC = 0.921, F1 macro = 0.786.
